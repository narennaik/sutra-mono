## where it lives

Read it at arm’s length. Notice what you don’t notice.

A coding font is read for hours, mostly at thirteen or fourteen points, mostly on a dark background. No terminal catches the eye; no letter is louder than its neighbours.

-- ad format spec ⇒ deterministic Moore machine
compile = emit ∘ minimise ∘ determinise ∘ parse

fold :: (F a → a) → Fix F → a
fold alg = alg ∘ fmap (fold alg) ∘ unfix

const step = (s: State, e: Event): State =>
  s.on[e.kind]?.(e) ?? s;   // total, never throws

## the composition set

Symbols drawn with the same pen, on the operator axis.

Most coding fonts borrow mathematical symbols from a fallback font. Sutra draws them, so g ∘ f reads as one line of thought.

cata alg = alg ∘ fmap (cata alg) ∘ unfix

## told apart at a glance

0OZero is narrower and carries a dot, never a slash.
Il1|Capital I has bars, l ends in a tail, 1 has a flag and a foot.
rn mThe r turns down early, so rn never fuses into m.
;:,.Dots run heavier than the stroke so punctuation survives at 11px.

## construction

A font that is generated, not drawn by hand.

skeleton ∘ pen
Each glyph is a centre-line swept by one pen. Weight is the pen’s width and nothing else.
|x|2.7 + |y|2.7 = 1
The bowl curve. Straighter sides than an ellipse, softer shoulders than a box.
pen 1 : 0.92
An elliptical nib. Horizontals come out 8% lighter, as a type designer would correct by eye.
600 / 1000 em
Every advance. x-height 520, cap 700, ascender 740, descender −200, operator axis 330.
