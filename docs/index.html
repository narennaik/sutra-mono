Chapter 1

It began as a gift, and one sentence.

Smooth, with a flow between the characters. Nothing unessential. Rounded, and feeling complete.

That was the whole brief for a coding font made for a friend. Most coding fonts start from a sans-serif and squeeze it into a fixed grid. Sutra started from a different question: what is the least you could draw and still have every letter read?

The answer was a single line per letter, the path a pen would take if it never lifted. The name comes from Sanskrit: a sūtra is a thread, and also a short rule that holds a whole idea in a line. Code is that kind of writing.

Chapter 2

One line, one pen. Weight is just the width of the nib.

Every letter is stored as its centre-line. The outline you read is what a single round-tipped pen leaves behind as it travels that line, so every end is the same soft curve and nothing is ever sharp. Drag the pen below: this is the font's real construction, running live.

Chapter 3

The soft square, somewhere between a circle and a box.

San Francisco feels calm partly because its rounds are not circles. Sutra makes that shape exact with a superellipse. At an exponent of 2 it is a circle, and as the number grows it becomes a box. Sutra lives at 2.7: straight enough that a column of code reads as walls, round enough that nothing has a corner.

Chapter 4

One bowl gives seven letters.

Once the curve existed, the lowercase almost drew itself. The same bowl with a stem on its left or right, rising or descending, is o, b, d, p, q, a and g. You learn one shape and get seven back, and they agree with each other because they are literally the same object.

Chapter 5

In code, a confusion is a bug.

In prose, context forgives a lot. In code there is no such mercy, so each easily confused pair is settled with the smallest difference that works, and nothing more.

0O

Zero is narrower and carries a single dot. No slash, so it never looks like Ø.

Il1|

Capital I has bars, l ends in a tail, 1 has a flag and a foot, and the pipe runs the full height.

rn m

The r turns down early, so rn never fuses into m.

;:,.

Dots are heavier than the stroke, so punctuation survives at small sizes.

Chapter 6

Symbols for people who compose functions.

Most coding fonts borrow mathematical symbols from a fallback font, in another weight and at another height. Sutra draws them with the same pen and sits them on the operator axis, so an expression reads as one line of thought. Choose a symbol to see it closer.

Chapter 7

Where it lives. Type here.

A coding font is read for hours, mostly at thirteen or fourteen points, mostly at night. The test is what you stop noticing.

Take it home.

Sutra Mono is free for any use under the SIL Open Font License, and it has been submitted to Google Fonts. It takes about thirty seconds to try.
